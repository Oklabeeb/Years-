Question 1 (Objective)

Evaluate log₁₀(25) + log₁₀(4) - log₁₀(0.1).

  1. 1
  2. 2
  3. 3
  4. 4
Solution: log₁₀(25 × 4) - log₁₀(10⁻¹) = log₁₀(100) - (-1) = 2 + 1 = 3.
Correct Answer: C
Question 2 (Objective)

If 3^(2x+1) - 28(3^x) + 9 = 0, find the values of x.

  1. x = -1 or x = 2
  2. x = 1 or x = -2
  3. x = 0 or x = 3
  4. x = 2 or x = 4
Solution: Let y = 3^x. Then 3y² - 28y + 9 = 0 ⇒ (3y - 1)(y - 9) = 0 ⇒ y = 1/3 or y = 9. Hence 3^x = 3⁻¹ ⇒ x = -1, and 3^x = 3² ⇒ x = 2.
Correct Answer: A
Question 3 (Theory - 10 Marks)

The 3rd term of an Arithmetic Progression (A.P.) is 10 and the 8th term is 25.
(a) Find the first term (a) and common difference (d).
(b) Calculate the sum of the first 20 terms.

Solution:
(a) T₃ = a + 2d = 10; T₈ = a + 7d = 25. Subtracting gives 5d = 15 ⇒ d = 3. Substituting into T₃ gives a + 2(3) = 10 ⇒ a = 4.
(b) S₂₀ = (20/2)[2(4) + (20 - 1)(3)] = 10[8 + 57] = 10(65) = 650.
