Question 1

Find the derivative dy/dx of y = (2x + 1)³ / (x² + 4).

  1. (2x+1)²(4x² - 2x + 24) / (x²+4)²
  2. (2x+1)²(2x² + 24) / (x²+4)²
  3. 6(2x+1)² / (2x)
  4. 3(2x+1)² / (x²+4)
Solution: By Quotient Rule: u = (2x+1)³, v = x²+4. u' = 6(2x+1)², v' = 2x. dy/dx = [6(2x+1)²(x²+4) - 2x(2x+1)³] / (x²+4)² = (2x+1)²[6x²+24 - 4x² - 2x] / (x²+4)² = (2x+1)²(2x² - 2x + 24) / (x²+4)².
Correct Answer: A
Question 2

Evaluate ∫ (4x³ - 6x² + 2) dx from x = 1 to x = 3.

  1. 32
  2. 48
  3. 56
  4. 64
Solution: Indefinite integral = x⁴ - 2x³ + 2x. At x = 3: (81) - 2(27) + 2(3) = 81 - 54 + 6 = 33. At x = 1: 1 - 2 + 2 = 1. Definite integral = 33 - 1 = 32.
Correct Answer: A
