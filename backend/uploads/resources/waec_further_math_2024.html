Question 1

Find the angle between the vectors a = 3i + 4j and b = 5i + 12j.

  1. 14.25°
  2. 22.62°
  3. 30.50°
  4. 45.00°
Solution: a·b = (3)(5) + (4)(12) = 15 + 48 = 63. |a| = √(3² + 4²) = 5; |b| = √(5² + 12²) = 13. cos θ = (a·b) / (|a||b|) = 63 / (5 × 13) = 63 / 65 ≈ 0.9692. θ = arccos(0.9692) ≈ 14.25°.
Correct Answer: A
